Plates, fonts, and label tables are fetched from [Fugleramme](https://github.com/arnegiacomo/fugleramme). They are not in this repository.

```bash
dotnet run --project src/BirdScreensaver -- fetch-assets
```

That writes a working copy under `%APPDATA%\BirdScreensaver\assets` and, when you are in a clone, also under `assets/` here.
